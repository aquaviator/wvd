# Wear Valley Digital

WVD services, product information and synthetic demonstrations built with Astro.
The existing manifest-driven commerce/marketing engine remains part of the site.
Google/Firebase is the selected application platform; development pushes are
permitted. Follow [WVD project authority](docs/WVD-PROJECT-AUTHORITY.md): continue
routine work without founder gates; request input only for missing user data,
elevated admin/configuration authority or additional spend. See also
[the development standard](docs/WVD-DEVELOPMENT-STANDARD.md).

The public enquiry page prepares a visitor-reviewed email draft using the fields
in the brief. It does not submit, persist, qualify or send enquiries. Timing,
budget and an existing website remain optional. The visitor sends through their
own email app or copies the full draft. Details changed after preparation clear
the old draft; long enquiries use copying rather than truncated mail links.
Analytics are disabled on this page, and without JavaScript the direct enquiry
email remains available. Hosted capture, spam controls, retention and final
privacy terms remain separate launch work.

The [portal foundation](tools/portal-proof/README.md) documents synthetic Firebase
registration, verified invitation acceptance, scoped Owner/Member access and
client/admin workflows. Use the [unattended development container](tools/development-container/README.md)
for portal verification and CI for public browser/accessibility evidence.
